# Демо-сайт натяжных потолков: как подогнать под клиента за 20-30 минут

Сайт статический: HTML, CSS и JavaScript без фреймворков и сборки. Открывается на GitHub Pages и любом хостинге.

## Файлы

| Файл | Что внутри | Менять под клиента? |
|---|---|---|
| `config.js` | Все данные: название, контакты, цвета, цены, галерея, отзывы, FAQ | **Да, основное** |
| `index.html` | Блок `<head>`: title, description, ссылки для соцсетей | Да, 6 строк |
| `privacy.html` | Политика обработки персональных данных (реквизиты подставляются из `config.js`) | Проверить текст с юристом |
| `manifest.webmanifest` | Название для иконки на экране телефона | Да, 2 строки |
| `img/` | Фото | Да, заменить на фото клиента |
| `app.js`, `styles.css` | Логика и оформление | Нет |

## Порядок (по времени)

1. **Компания, 5 минут.** `config.js` → `company`: название, город, телефон (два поля: как показывать и только цифры), часы, адрес, ИП/ИНН. `messengers`: ник Telegram, номер WhatsApp, ссылка на MAX. Ненужное выключить через `enabled: false`.
2. **Цвета, 2 минуты.** `theme.accent` - цвет бренда. `accentHover` - на 10-15 % темнее, `accentSoft` - очень светлый оттенок. Проверить, что белый текст на `accent` читается.
3. **Цены, 5-10 минут.** `pricing.textures` (цена за м² под ключ), `pricing.constructions` (доплата), `pricing.extras`, `minOrder`. Если владелец боится вилки, поставить `priceMode: "from"`.
4. **Факты и замер, 2 минуты.** `facts`, `measure`, `hero`.
5. **Фото, 5-10 минут.** Положить фото в `img/` в формате WebP или JPG и прописать пути. Галерея: для каждой работы два файла, `имя-600.webp` и `имя-1200.webp` (ширина 600 и 1200 px, пропорции 4 × 3). Фото для карточек калькулятора - 640 × 400 px. Лучше выбирать фото одной яркости: все светлые, днём.
6. **Отзывы и ссылки, 3 минуты.** `reviewSites` - рейтинг и ссылки на карточки компании в 2ГИС, Яндекс Картах, Авито. `reviews` - 3-4 реальных отзыва со ссылками.
7. **SEO, 2 минуты.** В `index.html` поменять title, description, og:title, og:description, адрес сайта и удалить строку `<meta name="robots" content="noindex">` (в демо сайт закрыт от поисковиков). В `manifest.webmanifest` - name и short_name.
8. **Подвал и политика.** Для боевого сайта: `company.demoNotice: false`. Политика обработки персональных данных обязательна по 152-ФЗ: шаблон лежит в `privacy.html`, ИП, адрес и телефон подставляются из `company`. Убрать из него плашку «Шаблон для демо» и проверить текст с юристом.
9. **Часовой пояс.** `company.timezone` (например, `Asia/Yakutsk`, `Europe/Moscow`): по нему сайт решает, что такое «сегодня», какие слоты на сегодня уже прошли и работает ли компания сейчас.

## Как уходят заявки

Сейчас (демо): после отправки формы открывается выбранный клиентом мессенджер с готовым текстом заявки, текст также копируется в буфер. Клиент нажимает «Отправить».

Позже (боевой режим): сделать серверную функцию (Яндекс Облако, Vercel и т. п.), которая принимает POST с JSON `{ text, name, phone, address, day, slot, channel, rooms, total }` и пересылает `text` в Telegram-бота. Адрес функции записать в `config.js → leads.endpoint`. Токен бота хранится только на сервере, во фронтенд его не класть. Если функция недоступна, сайт сам откатится на отправку через мессенджер.

## Публикация на GitHub Pages

1. Создать репозиторий, загрузить содержимое папки `site/`.
2. Settings → Pages → Source: Deploy from a branch, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет по адресу `https://<логин>.github.io/<репозиторий>/`. Этот адрес вписать в `company.siteUrl` и в `<head>` файла `index.html`.

После правок в `styles.css`, `app.js` или `config.js` увеличьте номер `?v=` у этих файлов в `index.html`, иначе браузеры посетителей до 10 минут показывают старую версию из кэша.

## Проверка локально

```
python -m http.server 8080
```
и открыть http://localhost:8080 (просто открыть файл двойным кликом тоже работает, но копирование текста в буфер там может не сработать).
